# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security problems.

Report security concerns privately to the maintainer through a GitHub private
security advisory if enabled for this repository, or through another private
channel you already use with the maintainer.

Include:

- A description of the issue
- Steps to reproduce it
- The affected files, endpoints, or workflows
- Any suggested mitigation if you have one

## Scope

Security-sensitive areas in this repository include:

- WebSocket bridge authentication and origin checks
- OSC and MIDI routing behavior
- GitHub Actions workflows and signing asset handling
- Any future deployment or device-management automation

## Handling

Reports will be reviewed privately first. Please allow time for validation and
remediation before public disclosure.
